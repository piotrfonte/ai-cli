# Capacitor Plugins Directory Skill

Comprehensive catalog of 80+ Capgo Capacitor plugins for adding native functionality to Capacitor apps.

## When to Use

- Deciding which plugin to use for a native feature
- Looking up the package name for a specific capability
- Comparing plugin options for the same use case
- Setting up a new native feature in a Capacitor app
