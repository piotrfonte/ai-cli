# React Router v6 Patterns Skill

Client-side routing with React Router v6 (react-router-dom ^6.2-6.26).

## When to Use

- Setting up routing (BrowserRouter or createBrowserRouter)
- Defining nested routes and layouts
- Navigating programmatically (useNavigate)
- Reading URL/search params (useParams, useSearchParams)
- Loading route data with loaders/actions (v6.4+)
- Protecting routes behind authentication
- Code splitting routes with lazy loading
