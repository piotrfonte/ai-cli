# Publishing to App Stores Skill

Complete guide to publishing Capacitor apps to Apple App Store and Google Play Store.

## When to Use

- Preparing an app for first submission
- Updating an existing app listing
- Debugging app store rejection issues
- Generating app icons and screenshots
- Configuring version and build numbers

## Resources

- `resources/ios-submission.md` — App Store Connect walkthrough, Info.plist, certificates, phased rollout
- `resources/android-submission.md` — Play Console walkthrough, build.gradle, release tracks, data safety
- `resources/assets-and-screenshots.md` — icon sizes, screenshot dimensions, feature graphic, generation scripts
