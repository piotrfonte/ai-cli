# Keyboard Handling in Capacitor Skill

Guide to managing keyboard behavior in iOS and Android Capacitor apps.

## When to Use

- Keyboard overlaps content or input fields
- Need to detect keyboard show/hide events
- Chat or messaging layout needs keyboard-aware positioning
- iOS input zoom issue (font-size < 16px)
- Android keyboard overlaps the layout
- Need to control the iOS accessory bar (toolbar above keyboard)
