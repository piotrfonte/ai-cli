# React + TypeScript Patterns Skill

React 18 patterns with TypeScript for components, hooks, TanStack Store state management, and code quality.

## When to Use

- Building React components with TypeScript props
- Writing custom hooks
- Managing state with TanStack Store or React Context
- Reviewing code quality or naming conventions
- Optimizing performance (memoization, code splitting)
